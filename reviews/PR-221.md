## Author intent

> - normalize CRLF and bare CR as logical line breaks in editor, transcript, Markdown, and both Lua/native text wrappers
- guard Lua frame lines and the native line-draw boundary so untrusted CR/LF bytes cannot reposition or overwrite terminal output
- keep raw tui_write semantics and live tool progress CR replacement unchanged
- add Lua/native parity coverage plus a real PTY regression for the host
