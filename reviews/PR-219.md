- title: Completion acceptance discards retained paste contents
  path: lua/psi/tui_runtime.lua line: 789-802
  severity: should_fix

  reason_flagged: Completion preserves text after the cursor but clears every paste registry entry.
  body: If that suffix contains a valid marker, chat.paste.clear leaves the marker visible without its backing content, so subsequent submission sends the literal marker instead of the pasted bytes; preserve the registry and reconcile it after replacement, matching pi-mono’s registry-preserving completion mutation at packages/tui/src/components/editor.ts:676-692.

  path: lua/psi/tui_runtime.lua line: 3057-3064
  severity: should_fix

  reason_flagged: Every target inside a wrapped marker snaps to its start without recording which continuation span was traversed.
  body: When a marker is wider than the available input width, repeated Down targets the same continuation and resets the cursor to the same marker start, preventing navigation to later lines; track continuation state and skip past the marker as pi-mono does at packages/tui/src/components/editor.ts:1426-1453.
- title: Supplementary Unicode uses a different compaction threshold
  path: lua/psi/tui_editor_paste.lua line: 24-26
  severity: should_fix
  category: bug

  body: A single-line paste of 501 supplementary characters remains inline in psi but becomes a 1002-character marker in pi-mono, changing both compaction and displayed count; count UTF-16 code units to match packages/tui/src/components/editor.ts:1206-1221.
