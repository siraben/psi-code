## Codex track (discovery)

```
PARITY_VERDICT: PARTIAL — pi-mono compares normalized MIME bases but preserves and requests the exact advertised MIME string (packages/coding-agent/src/utils/clipboard-image.ts:45-55, packages/coding-agent/src/utils/clipboard-image.ts:130-140); psi discards parameters before capture. The sink otherwise matches: pi writes image bytes to a random MIME-suffixed temp file, inserts its raw path at the cursor, and attempts text only when no image is returned (packages/coding-agent/src/modes/interactive/interactive-mode.ts:2925-2944). Pi also probes WSL PowerShell and converts unsupported image formats to PNG (packages/coding-agent/src/utils/clipboard-image.ts:268-296), which this PR explicitly excludes.
FINDINGS:
- title: Parameterized clipboard MIME targets are requested under the wrong name
  path: lua/psi/clipboard_image.lua line: 87-101
  severity: should_fix
  category: api_boundary
  reason_flagged: MIME discovery collapses each advertised target to its normalized base before the capture command uses it.
  body: A clipboard advertising only `image/png; charset=binary` is recorded as `image/png`, so wl-paste or xclip is asked for a target that was not offered and image paste falls through to text; retain the raw target alongside its normalized base, order by the base, and pass the raw value to the backend.
- title: Windows capture is not bounded by the 16 MiB byte limit
  path: lua/psi/clipboard_image.lua line: 56-63
  severity: should_fix
  category: performance
  reason_flagged: The PowerShell backend limits pixel count but writes the complete encoded PNG before any byte-size check occurs.
  body: A 100,000,000-pixel image can consume far more than 16 MiB of temporary storage before `read_file_limited` rejects it, so the advertised capture bound does not constrain Windows I/O; encode through a byte-bounded stream or otherwise enforce the encoded-size limit while writing.
PI_GAPS:
- Parameterized Wayland/X11 MIME targets are not preserved as pi-mono preserves the raw advertised value for capture (packages/coding-agent/src/utils/clipboard-image.ts:45-55, packages/coding-agent/src/utils/clipboard-image.ts:130-140).
- WSL PowerShell fallback and unsupported-format conversion, including BMP, remain intentionally omitted; pi-mono implements both (packages/coding-agent/src/utils/clipboard-image.ts:143-210, packages/coding-agent/src/utils/clipboard-image.ts:268-296).
- psi uses Ctrl-V on Windows, while pi-mono binds clipboard image paste to Alt-V on win32 (packages/coding-agent/src/core/keybindings.ts:112-115).
- psi rejects captures above 16 MiB, while pi-mono configures clipboard subprocess reads for up to 50 MiB (packages/coding-agent/src/utils/clipboard-image.ts:17-20, packages/coding-agent/src/utils/clipboard-image.ts:89-100).
```
