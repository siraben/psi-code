## Author intent

> - add best-effort system clipboard text readers for Termux, Wayland, X11, macOS, and Windows PowerShell
- prefer Wayland clipboard contents and avoid stale X11 fallback after a successful empty Wayland read
- bind `app.clipboard.paste` to Ctrl-V and insert normalized, control-filtered text at the cursor
- keep Vim normal/visual Ctrl-V and terminal bracketed-paste handling independent
